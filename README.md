## 🏠 Desde el Búnker

Soy **Alexis Alzate**, desarrollador de software colombiano.

Me gusta tomar problemas reales y convertirlos en herramientas que puedan usarse de verdad: **aplicaciones de escritorio, automatización de procesos y productos web**.

Mi enfoque actual está en **C#, .NET y Python**, mientras sigo aprovechando mi experiencia con **JavaScript, React y desarrollo web**.

> No me interesa coleccionar tecnologías. Me interesa entender cómo funciona un sistema, cómo se conectan sus piezas y cómo construirlo mejor.

### 🎧 LUJOURBAN

Tienda de beats construida **desde cero en Next.js** — sin depender de BeatStars ni pagar comisión por venta, con propiedad total de la plataforma.

- Backend en migración a **ASP.NET Core (.NET)**, con **Supabase/PostgreSQL** como base de datos.
- Pagos integrados con **Mercado Pago Checkout Pro** (REST directo + webhooks).
- Función SQL atómica que evita la doble venta de licencias exclusivas.
- Notificaciones automáticas a productores en cada venta, vía **Resend**.

## 🧭 Cómo pienso el desarrollo

Para mí programar no es solamente escribir código.

- 🧩 Entender cómo se divide un sistema en componentes.
- 🔄 Comprender cómo viajan los datos y cómo se conectan las piezas.
- 🏗️ Diseñar soluciones mantenibles en lugar de parches aislados.
- 🐛 Buscar la causa real de un problema antes de corregirlo.
- ⚙️ Detectar procesos repetitivos que vale la pena automatizar.
- 📚 Estudiar el código que construyo para comprender el **por qué**, no solamente el **qué**.
